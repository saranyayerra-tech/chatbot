# Basic Chatbot using Python
## Objective
Create a simple rule-based chatbot that responds to predefined user inputs.
## Technologies Used
- Python
## Concepts Used
- if-elif
- Functions
- While Loop
- Input/Output
## Features
- Greets the user
- Answers simple questions
- Ends the chat when the user types "bye"
## How to Run
1. Open the project in VS Code.
2. Run:
   python chatbot.py
3. Start chatting with the bot.# chatbot
